This file defines unit tests for a custom user model integration in an agent framework. It includes two mock classes (UserCustomLLM simulating a large language model and CustomLoop simulating a custom agent loop) and three test methods: test_user_custom_model_fast_mode tests basic agent invocation with a custom LLM, test_user_custom_model_plan_mode_with_custom_loop validates the plan mode behavior using the custom loop, and test_user_custom_model_streaming_path verifies the streaming response path. Each test uses MockAgent and MockConfig to configure the agent environment and asserts expected responses and state transitions.
