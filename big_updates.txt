Core Design Principles
1. Registry Pattern

The framework should dynamically discover and register devices/plugins.

Benefits:

Easy plugin management
Extensible architecture
Runtime device loading
Loose coupling
2. Dependency Injection (DI)

Avoid hardcoded dependencies.

Benefits:

Better testing
Easier scaling
Cleaner architecture
Swappable implementations
3. Event-Driven System

Devices emit events instead of polling everywhere.

Examples:

motion_detected
human_detected
temperature_high
camera_frame_ready
4. Unified Data Format

Every device returns standardized data.

Example:

{
    "device_id": "temp_01",
    "type": "temperature_sensor",
    "value": 28.5,
    "unit": "C",
    "timestamp": 1712345678
}

Registry Pattern Example
registry.py
class DeviceRegistry:
    def __init__(self):
        self._devices = {}

    def register(self, name, device):
        self._devices[name] = device

    def get(self, name):
        return self._devices.get(name)

    def all(self):
        return self._devices

Dependency Injection Container Example
container.py
class Container:
    def __init__(self):
        self.services = {}

    def register(self, name, service):
        self.services[name] = service

    def resolve(self, name):
        return self.services[name]
Camera Plugin Example
webcam_plugin.py
import cv2
from core.interfaces import DeviceInterface

class WebcamPlugin(DeviceInterface):

    async def connect(self):
        self.cap = cv2.VideoCapture(0)

    async def read(self):
        ret, frame = self.cap.read()

        return {
            "type": "camera_frame",
            "success": ret,
            "frame": frame
        }

    async def disconnect(self):
        self.cap.release()

Event Bus Example
events.py
class EventBus:
    def __init__(self):
        self.listeners = {}

    def on(self, event_name, callback):
        if event_name not in self.listeners:
            self.listeners[event_name] = []

        self.listeners[event_name].append(callback)

    def emit(self, event_name, data=None):
        callbacks = self.listeners.get(event_name, [])

        for callback in callbacks:
            callback(data)
Example Event Usage
event_bus = EventBus()

def motion_alert(data):
    print("Motion detected:", data)

event_bus.on("motion_detected", motion_alert)

event_bus.emit("motion_detected", {
    "sensor": "IR_01"
})
